# AI, Machine Learning and Data Mining in Action

Guest lecture materials by **Caihao (Chris) Cui** for La Trobe University's **CSE5ML** and **CSE5DMI** students, shared publicly for anyone interested in the topics.

These lectures connect what you learn in class with how teams build and use AI systems in industry. You will explore AI and machine learning fundamentals, how models move into production (MLOps), and the technical and teamwork skills used in AI careers. The main lecture also introduces generative AI and Agentic AI, including a workflow that brings together language models, tools, code, and human input.

## Start here

Begin with the shared lecture, then choose the case study for your course:

- **Both courses:** [Main lecture](latrobe/A-CSE5ML%26DMI-Guest-Lecture.excalidraw) — Review the fundamentals, explore how AI works at scale, and consider how to prepare for work in the field.
- **CSE5ML:** [Recommendation systems](latrobe/B-Case-Study-01-CSE5ML.excalidraw) — How can a system choose which products or content to recommend to a user? Explore user preferences, system design, and how recommendation models are put into operation.
- **CSE5DMI:** [Entity matching](latrobe/C-Case-Study-02-CSE5DMI.excalidraw) — How can we tell whether records from different sources refer to the same customer? Explore incomplete or conflicting data, grouping matching records, and keeping identifiers consistent as data changes.

## Open the materials

**For a quick look**, browse the [PNG images in `archive/`](archive/). These are dated snapshots of earlier lecture materials and can be viewed without an editor.

**For the current lecture or to explore the diagrams**, use the `.excalidraw` files linked above:

1. Open the file link and download the raw file from GitHub.
2. Open [Excalidraw](https://excalidraw.com/) in your browser.
3. Drag the downloaded file onto the canvas to view and edit it. Zoom in to read individual diagrams and pan to move between topics.

Use the current main lecture file for the Agentic AI content added in September 2026; archived images may not include later updates. You do not need to install code or run a build to use these materials.

To create your own diagrams, download the [drawing template](template.excalidraw) and open it in the same way.
